# ValeDouro

Migração Git do Compêndio de Valedouro baseada na **v3.18 validada**.

A estrutura separa HTML, CSS, JavaScript, dados e artes para facilitar versionamento e evolução do jogo.

- `index.html` — interface do compêndio.
- `css/compendio.css` — estilos.
- `js/compendio.js` — comportamento da interface.
- `data/compendio.json` — registros estruturados.
- `assets/artes/` — artes individuais em WebP.
- `legacy/` — referência da migração.

A v3.18 é o marco canônico usado nesta migração.
