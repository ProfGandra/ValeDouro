# ValeDouro

Repositório do compêndio público e das artes oficiais do cenário de Valedouro (D&D 5.5).

## Estrutura
- `compendio/` — versões do compêndio HTML.
- `artes/personagens/` — fichas e artes oficiais de personagens.
- `artes/locais/` — fichas e artes oficiais de locais.

Versão atual do compêndio: **v3.14**.
